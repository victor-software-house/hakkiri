A code span is no word of a `sequence` rule's run, so no token names it by tag or pattern, and a negated token holds at it.
A rule of a noun and a verb, such as `ThingsSpeakNoun`, no longer flags `` `flag` says ``.
A token that reads one word reads the noun that a preposition before the span attaches it to, so the run starts at `notice` in `` the notice for `cmd-7` says ``.
On nine repositories this removes 72 alerts and adds 17.
Vale flags such a span, because it reads the span as a run of `*`.
